第 3 / 7 步

支付流程为什么要改

修改原因
两个并发请求可能同时通过支付状态检查，导致同一个订单被重复扣款。
改的核心思想
在读取和判断支付状态之前先取得订单锁，让检查与扣款成为同一条受保护的主线。
场景
以前检查 → 扣款
现在加锁 → 检查 → 扣款
